TermeClé JSONDéfinitionExemples
SKILL skill Capacité analytique principale d'YRYS. Il en existe 4, fixes. Chaque bénéfice est rattaché à exactement 1 skill. detection, counting, heatmap, quality
TYPE SKILL skill_item Sous-mode d'un skill. Précise la nature exacte de l'analyse. Un bénéfice choisit 1 type skill parmi ceux du skill parent. counting_people, detection_zone, heatmap_trajectory
CLASS FAMILY category (key) Famille d'objets détectables. Regroupe des classes du même domaine. Les class families compatibles dépendent du skill choisi. human, transport, object
CLASS category.items[].id Objet concret détecté par le modèle IA. Un bénéfice peut cibler une ou plusieurs classes. Une class appartient à une seule class family. silhouette, foule, voiture, fissure

Video & Upload

Gestion des fichiers vidéo comme sources d'analyse.

EndpointMéthodeDescriptionParamètresRéponse
/api/videosGET Liste tous les fichiers vidéo disponibles dans /videos/ —{ videos: string[] }
/api/videos/uploadPOST Upload un fichier vidéo (multipart/form-data) file: UploadFile{ message, filename }
/api/videos/optimize/{name}POST Ré-encode la vidéo en H.264 pour un streaming optimal name: str (path){ message, filename }
/api/videos/{name}/frameGET Capture une frame JPEG de la vidéo (snapshot) name: str (path)JPEG image
/api/videos/{name}/infoGET Métadonnées vidéo : résolution, FPS, durée, codec name: str (path){ width, height, fps, duration, codec, ... }
Règles métier
  • Formats acceptés : .mp4, .avi, .mkv, .mov, .webm
  • L'optimisation utilise ffmpeg -c:v libx264 -preset fast -crf 23
  • Les vidéos sont stockées dans /videos/ (plat, pas de sous-dossiers)
  • La frame est capturée à la position 0 (première frame lisible)

Blur (Floutage)

Floutage automatique des visages dans les flux vidéo (zone haute de la bbox YOLO).

EndpointMéthodeDescriptionRéponse
/api/blurGET État actuel du floutage{ enabled: bool }
/api/blur/togglePOST Bascule on/off{ enabled: bool }
/api/blur/{state}POST Force l'état (on ou off){ enabled: bool }
Fonctionnement technique
  • Appliqué sur les 30% supérieurs de chaque bounding box détectée par YOLO
  • Utilise un gaussian blur via OpenCV (cv2.GaussianBlur)
  • Thread-safe via blur_lock
  • Actif sur tous les streams simultanément (flag global)
  • N'affecte pas la détection YOLO elle-même (appliqué après l'inférence)
